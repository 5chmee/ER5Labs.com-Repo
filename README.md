# ER5Labs

Personal hub & portfolio for **Emad Rafiq** — [er5labs.com](https://er5labs.com).

A light-first, minimal site built with [Astro](https://astro.build). The homepage
is a split-flap **departure board** linking to the site's destinations:

- **Projects** — current & past work, each with its own detail page
- **Skills** — tools & technologies
- **Experience** — career & work history
- **Entries** — writing / notes
- **Playground** — experiments & demos

Features a pull-cord lamp that toggles light/dark, and a hover-expand side nav.

## Develop

```bash
npm install
npm run dev
```

The dev server prints a local preview URL (usually http://localhost:4321).

## Build

```bash
npm run build      # outputs static site to dist/
npm run preview    # preview the production build locally
```
